# Telephone Book 📒

## About

A simple contact management application built with Python and Tkinter.

## Features

- Add contacts with full name, phone number, and Gmail.
- Display contacts in a table.
- Save and load contacts using JSON.
- Validate required fields and basic email format.

## Technologies

- Python
- Tkinter
- JSON

## How to Run

1. Install Python 3.
2. Run the following command:

   ```bash
   python telephone.py
   ```

## Data Storage

Contacts are stored in `contacts.json` and loaded when the application starts.
